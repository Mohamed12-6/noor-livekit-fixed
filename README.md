# Noor — منصة تعلم القرآن (Next.js + Tailwind)

منصة تعلم قرآن بـ **Next.js 15 + Tailwind CSS** مع باك اند (Prisma + SQLite)، لوحة أدمن محمية،
حالة اتصال المدرس، مكالمات فيديو WebRTC، ودفع Stripe (وضع تجريبي بدون مفاتيح).

---

## 🚀 التشغيل (مهم: 3 خطوات بالترتيب)

```bash
npm install          # 1) تثبيت الحزم
npm run setup        # 2) إنشاء قاعدة البيانات + إنشاء الحسابات (إلزامي!)
npm run dev          # 3) تشغيل الموقع على http://localhost:3000
```

> ⚠️ **لو نسيت الخطوة 2 (`npm run setup`) هيظهر خطأ في تسجيل الدخول** لأن قاعدة البيانات
> فاضية ومفيش حساب أدمن. لو حصلت مشكلة دخول في أي وقت، نفّذ `npm run setup` تاني.

## 🔐 بيانات الدخول

| الحساب | البريد | كلمة المرور | الصفحة |
|---|---|---|---|
| **أدمن** | `admin@noor.com` | `admin123` | `/admin` (لوحة الإدارة) |
| معلم | `mustafa@noor.com` | `teacher123` | `/teacher` (لوحة المعلم) |
| معلم | `alaa@noor.com` | `teacher123` | `/teacher` |

- صفحة تسجيل الدخول: **`/login`**
- صفحة الأدمن `/admin` محمية على السيرفر (middleware + JWT في cookie httpOnly) — أي حساب غير أدمن يتحوّل تلقائياً لصفحة الدخول.
- لتغيير كلمة المرور: عدّل `prisma/seed.mjs` (غير `admin123`) ثم `npm run setup`.

## 🧑‍🏫 حالة المعلم (أونلاين / أوفلاين)

- كل معلم ليه لوحة `/teacher` فيها زر «أنا متصل الآن» + heartbeat كل 30 ثانية.
- الطالب يشوف الحالة في `/teachers` (تحديث كل 15 ثانية) ويزرّ المكالمة بس لما المعلم متصل.
- الأدمن يقدر يشغّل/يوقّف اتصال أي معلم يدوياً من `/admin`.

## 📞 مكالمة الفيديو (زي واتساب)

الطالب يضغط «مكالمة فيديو» → المعلم يسمع رنين في لوحته → يقبل → اتصال WebRTC مباشر
(فيديو + صوت + كتم ميكروفون + إنهاء).
> الإشارات حالياً عبر استعلام دوري من قاعدة البيانات — كافية للتجربة والنطاق الصغير.
> للتوسّع الكبير بدّلها بسيرفر WebSocket (نقطة التبديل: `/api/calls/signal`).

## 💳 الدفع

- السعر الافتراضي **$15** — يتغيّر من لوحة الأدمن فوراً.
- مع مفاتيح Stripe (ضيفها في `.env`): دفع حقيقي عبر Stripe Checkout + webhook تأكيد تلقائي:
  ```
  STRIPE_SECRET_KEY="sk_test_..."
  STRIPE_WEBHOOK_SECRET="whsec_..."
  ```
- بدون مفاتيح: بوابة محاكاة واضحة التسمية لتجربة المسار كاملاً (هذا هو وضع الاختبار الرسمي لـ Stripe).

## 🗂 بنية المشروع

## 💬 زرار «تواصل» (شات واتساب / مكالمة هاتفية)

كل معلم ليه **رقم واتساب** متسجّل في قاعدة البيانات، والطالب في `/teachers` بيلاقي زرار **«تواصل»**
جنب زرار «مكالمة فيديو»، وبيطلّع قائمة اختيارين:

| الاختيار | الرابط |
|---|---|
| **محادثة واتساب** | `https://wa.me/<number>` (يفتح واتساب على شات جاهز) |
| **مكالمة هاتفية** | `tel:+<number>` |

- الأرقام بصيغة دولية بدون + وبدون صفر في الأول: `201014546662` (مصر +20).
- مدخل الأدمن يقبل `01014546662` أو `201014546662` وهو **بيحوّلها تلقائياً** للصيغة الدولية.
- الزرار بيتقفل لو المعلم أوفلاين أو لسه مفيش رقم ليه.

### 🔢 تغيير أرقام التواصل (من الأهم للمهم)

1. افتح **`/admin`** بحساب الأدمن.
2. انزل لجدول **«المعلمون وحالة الاتصال»**.
3. في عمود **«رقم الواتساب (تواصل)»** اكتب الرقم (مثال: `01014546662`) واضغط **حفظ**.
4. التغيير بيظهر فوراً لصفحة الطلاب (بدون إعادة تشغيل السيرفر).
5. **تغيير دائم من الكود:** عدّل `whatsapp` في `prisma/seed.mjs` ثم نفّذ `npm run setup`.
6. **ملاحظة:** الرقم الحالي لـ مصطفى و آلاء **نفس الرقم** (`201014546662`) — عدّل رقم آلاء لو كان مختلف.

## 📖 القرآن (١١٤ سورة + أصوات شيوخ)

- كل السور الـ**114** موجودة في `src/data/content.ts` (اسم السورة بالعربي والإنجليزي + عدد الآيات).
- الأصوات من **Islamic Network Quran CDN**: `https://cdn.islamic.network/quran/audio-surah/128/<edition>/<رقم السورة>.mp3`
- الشيوخ المتاحون حالياً: **مشاري راشد العفاسي** (`ar.alafasy`) و **عبد الله بصفر** (`ar.abdullahbasfar`).
- **لإضافة شيخ جديد:** ضيف سطر في مصفوفة `reciters` في `src/data/content.ts`، والرابط بيتولّد تلقائياً.
- اختيار الشيخ + تشغيل/إيقاف + شريط تقدّم + إعادة المحاولة عند فشل التحميل، كله في `quran-audio-player.tsx`.

## 🧯 حل مشاكل شائعة

| المشكلة | الحل |
|---|---|
| «بريد أو كلمة مرور غير صحيحة» مع البيانات الصحيحة | نفّذ `npm run setup` (القاعدة فاضية) |
| `Error: Environment variable not found: DATABASE_URL` | تأكد من وجود ملف `.env` (مرفق) |
| زرار «تواصل» مقفول | لازم المعلم يكون متصل + الأدمن لازم يحفظ رقمه في `/admin` |
| المكالمة لا تفتح | لازم المعلم يكون «متصل الآن» + السماح للكاميرا/الميكروفون في المتصفح |
| الدفع يحوّل لبوابة محاكاة | طبيعي بدون مفاتيح Stripe — أضف `STRIPE_SECRET_KEY` |
